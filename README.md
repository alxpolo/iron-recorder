# Iron Recorder PWA v2

This patch changes the iPhone import control and fixes stale service-worker caching.

Replace your existing GitHub repository files with:
- index.html
- manifest.webmanifest
- sw.js

Then open the Pages site in Safari with `?v=2` appended once.
When the header says `v2`, remove the old Home Screen icon and add it again.

For iPhone USB recorders: connect the recorder, tap Choose recordings, browse to the recorder in Files, and select the audio files.
